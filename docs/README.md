The dated validation review, progress, continuation and session handoff documents
describe historical snapshots. They preserve why records and campaigns exist;
their worker counts, queue paths and completion claims are not current status.
`PLAN.md`, `TODO.md` and `FINDINGS.md` also contain historical decisions. Inspect
addressed records and fresh QC before reporting a property as available.

Current result coverage comes from `redox.validation.readiness`; numerical
agreement comes from a new isolated table review and its independent audit.
Verified candidate snapshots carry their own source and input fingerprints;
changing code or evidence can intentionally withdraw an older snapshot.
