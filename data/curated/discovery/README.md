# Curated discovery evidence

These files describe source molecules and measurements. They do not replace
exact-graft calculations. Every source keeps its solvent, electrode reference,
supporting electrolyte, molecular charge, counterions and original-study identity.

| File | Contents | Current use |
| --- | --- | --- |
| [Aryl viologens](aryl_viologen_2025.json) | Seven isolated parent salts/components; aqueous conditions kept explicit | Source-directed O-graft preparation; no MeCN labels |
| [NDI electrolyte series](ndi_electrolyte_2024.json) | Five parents, nine salts, MeCN formal potentials, solubility, diffusion and heterogeneous rates | Condition-specific source evidence; explicit electrolyte/aggregation treatment required before calibration |
| [Cata diimides](cata_diimides_2024.json) | Four source compounds and eight half-wave potentials in CH2Cl2 | Alternative imide cores; graph transcription pending; no MeCN labels |

The [source catalog](../../../config/discovery_sources.json) links original
publications, licenses and acquisition records. The [exploration guide](../../../docs/CANDIDATE_EXPLORATION.md)
describes the current search and selection policy. Structure, condition and
source checks are recorded with each campaign under `results/discovery/`.
