# Figure 2 — the nine-stage screening pipeline

**File:** `fig2_pipeline.png` (300 dpi). PNG only, per the figure style contract.

**Figure 2. A single reproducible driver takes each grafted motif from structure
to quality-checked redox properties in nine stages.**
The driver `redox.workflows.motifs.commands()` runs: (1) build the grafted-motif
model (RDKit ETKDG ensemble, 4-methylbenzyl cap, redox states per motif);
(2) UMA MLIP gas-phase pre-optimization (charge-/spin-aware seed); (3) DFT
geometry optimization in SMD(MeCN) for each state [neutral / ox1 / ox2] at
r²SCAN-D4/def2-SVP(D) with a GFN2-xTB ALPB(MeCN) warm start, the three states run
concurrently; (4) refined single-point energies at ωB97M-V(VV10)/def2-TZVPD in
SMD(MeCN) using one diffuse basis for every charge state and for the Fc reference;
(5) two-tier thermochemistry; (6) derived properties kept as separate quantities;
(7) QC coverage and cross-point consistency; (8) Pareto ranking; and
(9) an independent arithmetic audit of the exported tables. Each stage is
addressed by content hash, so a change in geometry, protocol, or (charge,
multiplicity) resolves a new record rather than overwriting an old one. Boxes are
coloured by compute resource (legend): GPU/DFT, GPU/ML (UMA), CPU, and QC/scoring.
The inset tabulates the level of theory and standard-state conventions
(manuscript Table 1). External experimental validation is not shown here; it is
Figure 4.

**Method note — two-tier thermochemistry (stage 5).** The *pool-wide* ranking tier
is a GFN2-xTB RRHO correction on the DFT+SMD geometry. It is cheap enough to apply
identically across the pool, and on the experimental benchmark it is no less
accurate than the native tier (MAE 0.232 V vs 0.247 V). The *lead-confirmation* tier is a native solution DFT Hessian
(r²SCAN-D4/def2-SVP(D)/SMD) with a quasi-RRHO treatment of low-frequency modes; it
needs a GPU and much disk space, so it is run only to confirm shortlisted leads. This is a deliberate two-tier design, not a
fallback.

**Interpretation / caveats.**
- The stage 6 properties (E° vs Fc, usable capacity, outer-sphere λ_o, inner-sphere
  λ_i, disproportionation) are **computed and reported separately and never
  combined**; stage 8 produces **no weighted-sum score**.
- QC failures (stage 7) are **held, not dropped** (see Figure 3).
- λ_i is treated as qualitative/SI (gas energies on single-conformer SMD
  geometries); a computed property does not show that a molecule can be made or will
  perform well.
