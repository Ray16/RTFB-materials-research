# xTB source used to independently check thermodynamic equations

These unchanged files are from xTB v6.7.1:
https://github.com/grimme-lab/xtb/tree/v6.7.1

They retain their original copyright and license headers. xTB is distributed
under GNU LGPL version 3 or later. The LGPL-3 and GPL-3 texts are included here.
The committed qualification certificate records the hashes of the exact source
files used by the independent review. They are evidence inputs, not a replacement
for the installed xTB library, whose separate binary hash is also recorded.
