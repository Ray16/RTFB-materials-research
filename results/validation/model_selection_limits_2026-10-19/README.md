# Selection limits are separate from calculated values

The evidence-bound review in `config/model_validation_limits.json` scopes the
observed phenothiazine second-oxidation problem by molecular core, charge pair
+2/+1 and catholyte role. A one-electron +1/0 path, anolyte path, unrelated core
or nominal electron/mass calculation is unaffected. A declared second step stays
in scope even if the predicted window walk stopped before reaching it.

The scorecard retains model potentials and path capacities as explicit model
estimates. Pareto selection marks voltage, window-derived capacity and associated
stability objectives unqualified for this scope, preventing primary-front
membership or dominance while retaining a partial-information row. The verified
candidate workbook withholds the qualified accessible capacity and separately
exports the original model estimate, status and source evidence. Nominal capacity
and the calculated potentials remain unchanged. Experimental residual statistics
do not invoke this selection gate: the bad second-wave point remains included.

The independent audit reads the scope/evidence itself and reconstructs the same
selection decision, without importing the primary policy predicate. Missing
review data fails explicitly; stale evidence, a new unreviewed protocol or an
unknown clearance status cannot silently clear the scope. Both table and candidate
input inventories track the backing evidence bytes. The final suite passes
540 tests. Source-dependent table verification is required before promotion.

The final review passed **31,850 independently reconstructed checks with zero
arithmetic discrepancies** and an unchanged input inventory. A second inventory
check passed before `results/validated/current` was promoted. The first review
was withdrawn because dependency tracking changed during that run; it was not
promoted. Its numerical pass does not override its failed freshness check.

This checkpoint qualifies the software and table selection policy. Refreshing
the candidate feed and slides is the next publication milestone. Physical
accuracy, the second-wave model discrepancy and solution kinetics remain open.
