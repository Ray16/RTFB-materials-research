# Neutral-partner SVPD sensitivity: five checked controls

Five existing benchmark neutral partners are independently reoptimized with r2SCAN-D4/def2-SVPD/SMD(MeCN), then evaluated with the uniform active ωB97M-V/def2-TZVPD electronic protocol and a derivative-checked SVPD Hessian. [plan.json](plan.json) fixes the five identities, original values, source hashes and numerical settings. [start_verification.json](start_verification.json) records actual workers on three H100s and two 32-GB V100s, with disjoint two-core sets, all six native caps=2 and ordinary GPU reservations. The same wave includes one separate H100 saved-trimer force check.

All five controls pass independent reconstruction: [complete review](../../reviews/2026-10-22/neutral_basis_complete/summary.json). First-potential changes are -11.7 to -35.1 mV, with original anion/Fc fixed. Nuclear corrections change by -7.8 to -21.3 meV and geometry/SP energies by -0.4 to -13.8 meV. These include geometry/conformer relaxation and are not fixed-geometry basis effects. The alternative-basis records carry their own actual protocol identity and do not claim the primary SVP native certificate. The existing basis-independent, certified projected qRRHO integrator is reused only after finite/symmetry/stationarity/spin and sampled-column checks. Primary files are never modified. The comparison separates nuclear thermal change and geometry-induced active-SP change, with existing anion and Fc held fixed. This does not fully rebenchmark Fc or establish basis convergence.

Raw checkpoints: `calcs/validation/neutral_basis_2026-10-22/`. Producer: `scripts/validation/neutral_basis_sensitivity.py`; launch: `scripts/validation/launch_review_controls.py`. Each task preserves gradient evaluations, returned opt.xyz, Hessian, displaced calculations/derivative summaries and its final status; inspect the actual status rather than treating a launched wrapper as completion. No automatic retries overwrite failed records.
