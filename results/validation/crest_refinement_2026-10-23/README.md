# Conformer follow-up and candidate decision checks

The workflow separates final-source preparation, resource qualification,
electronic convergence, native thermochemistry and finite-set interpretation.
Tests exercise Hartree-only XYZ parsing, intermediate-frame exclusion, source
completion, backbone configuration, atom mapping after XYZ reordering, duplicate
rediscovery, strictly nested prefixes and context-consistent cycle joins. RAM
tests count promised startup growth without reserving observed unique allocations
twice. Launch tests re-poll an owned observer without creating a duplicate and
preserve unconfirmed outcomes. Unverified devices consume no molecule attempt.

The [twelve-state baseline](../../reviews/2026-10-23/baseline_native_complete/summary.json)
reconstructs independently from raw electronic and nuclear records. Wider sampling
remains open. Exact PMDI geometry/route review, source-search starts and capacity
bounds are recorded with the [candidate campaign](../pmdi_occupancy_2026-10-23/README.md).

Capacity tests compare the analytic model with all eight exact occupancy graphs,
retain chloride/scaffold mass and refuse charged viologen without an ionic mass
convention. Bounds are necessary conditions, not achieved capacity or an all-axis
pass. Application cutoffs remain unset.

The [memory controls](../smd_build_memory_2026-10-23/README.md) separately compare
full original and compact energies, optimized coordinates, gradients and Hessians
for both spin classes. Larger-geometry resource qualification is separate.
Software/control checks do not establish experimental material performance.
