# Consolidated manuscript reviewer bundle, version 2

[Archive and status](current.json) · [Standard-library replay](stdlib_replay.json) ·
[Source closure](closure.json) · [Neighbor Hessian replay](neighbor_native_isolation.json) ·
[Control replay](controls_native_isolation.json) · [Earlier bundle](../manuscript_bundle/README.md)

This local bundle adds the candidate library and nine dependencies needed by the
projected-thermal certificate to the earlier source and four overlapping raw-state
packages. The candidate manifest and certificate dependencies were checked after
extraction. The earlier bundle remains available as a historical snapshot.

This bundle predates the [TEMPO exact-support assessment](../../grafting/tempo_exact_support_2026-10-26/README.md)
and does not contain the newly used TEMPO local-graft state records. A successor
raw-state package is needed for the current manuscript before deposition.

The archive was extracted outside the original checkout. Standard-library replays
of five stages passed with reads from the original project blocked. In an isolated
NumPy 2.2.6 environment, 13 neighbor Hessian mode sets and the monatomic partition,
and eight numerical-control geometry/Hessian records were reconstructed from the
same version 2 archive. These checks do not repeat the original SCF, stationarity,
spin or experimental validation. Source closure does not requalify the native GPU
or projected-thermal production entrypoints.

Archive location, SHA-256, source commit and replay paths are in [current.json](current.json).
The source is prepared by `scripts/release/prepare_manuscript_bundle_v2.py` using
`config/manuscript_reviewer_bundle_v2.json`. For the small CPU example and details
of the included packages, see the [earlier bundle guide](../manuscript_bundle/README.md).
Third-party source PDFs and XML are excluded and cited by DOI in the manuscript.

This is a **local reviewer artifact**, not a public deposit. Data licensing, author
metadata and an archival DOI remain open; this replay does not establish broad
environment portability or conformer-ensemble convergence.
