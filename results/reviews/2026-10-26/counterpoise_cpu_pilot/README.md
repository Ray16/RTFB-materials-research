# CPU counterpoise resource pilot

The independently reviewed [one-spacer geometry](../counterpoise_control/prepared_one_spacer_cpu_geometry.json) defines a 38-atom frozen phthalimide pair and a common-grid gas counterpoise protocol. A CPU-only pilot evaluates only the A-own term, with durable SCF checkpoints, a sampled 32 GiB host-RSS guard and source-bound inputs. The sampled guard may detect a transient allocation only after it occurs. A failed attempt preserves its SCF checkpoint; a source-matched restart into a new output directory is implemented, with a [small-control restart check](restart_check.json) that reproduces the reviewed energy. The pilot is not a full five-term counterpoise interaction and does not correct any acetonitrile result.

The prospective geometry plan is in `results/validation/local_counterpoise_2026-10-26_cpu_one_spacer/`; its GPU fields describe the original alternative GPU execution path. The separate CPU pilot writes under `calcs/local_motif_counterpoise/cpu_one_spacer_2026-10-26/`. The [tests](tests_final.xml) check the reviewed input and durable-storage gate. Pilot completion and an independent resource/physical review are required before expanding the CPU calculation.

The [initial restart check](initial_restart_diagnostic.json) failed its energy tolerance; the initial adapter did not enforce the common full-complex auxiliary factory and did not explicitly set the grid levels. Both settings were corrected; the corrected water control reproduces the reference, but this does not qualify the larger pilot or prove separate contributions of the two changes.

The [launch observation](launch_verification.json) records the CPU pilot running on eight allocated cores. At that snapshot the kernel was active but no SCF iteration or checkpoint had yet been written; current progress is in the shared raw directory. This is not an admitted energy.
