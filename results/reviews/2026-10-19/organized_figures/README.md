# Candidate figure organization

The maintained collection is [results/candidates/figures](../../../candidates/figures/README.md).
The browser remains at its original root path. Main comparisons, molecular
structures, supplementary figures, data and metadata have separate folders.
The generator, browser links, slide publisher and checkers use the same layout.
Only generated flat files matching their previously recorded checksums were
removed after publishing their replacements. Scientific source records were not moved.

The refreshed collection contains 75 designs and 18 formal redox-state drawings.
All 589 software tests and all 24 local browser links resolve; 138 browser/data/export checks and 114
independent structure checks passed. The checked slide deck has 55 pages, with
comparison figures on pages 37–40. This records organization and rendering
checks; it does not extend scientific validation.
